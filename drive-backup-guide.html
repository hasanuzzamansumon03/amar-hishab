🛠️ সমস্যা হলে (FAQ)

৪০৩ / access_denied এরর দেখাচ্ছে?
ধাপ ৩-এর ৪ নম্বর কাজ (Test user যোগ) হয়নি। ফিরে গিয়ে নিজের জিমেইল Test user হিসেবে যোগ করুন।
400 / origin_mismatch এরর?
ধাপ ৪-এর ৩ নম্বরে বসানো ঠিকানাটি হুবহু মিলছে না। https://hasanuzzamansumon03.github.io — https সহ, শেষে / ছাড়া, বানান একই রকম কিনা আবার মিলিয়ে দেখুন, ঠিক করে Save করুন।
বাটনে চাপার পর কিছুই হচ্ছে না / পপ-আপ খুলছে না?
Chrome-এ পপ-আপ ব্লক হতে পারে — অ্যাড্রেস বারের পাশের আইকনে ট্যাপ করে Pop-ups → Allow করুন। ইন্টারনেট চালু আছে কি নাও দেখুন।
"invalid_client" এরর?
Client ID টি পুরোটা কপি হয়নি (শেষে .apps.googleusercontent.com পর্যন্ত পুরোটা লাগবে)। আবার কপি করে সেটিংসে বসান।
Credentials/Clients মেনুতে ঢোকার পর কিছু বানাতে দিচ্ছে না?
আগে ধাপ ৩ (OAuth consent/Auth) সম্পূর্ন করতে হবে — তারপর Client বানানো যাবে।
একাধিক জিমেইল আছে, কোনটা দেব?
যে জিমেইলের ড্রাইভে ব্যাকআপ রাখতে চান — Cloud Console-এ, Test user-এ এবং ফোনের অনুমতির সময় একই জিমেইল ব্যবহার করুন।
টাকা কাটবে কোনোদিন?
না। এই ব্যক্তিগত ব্যবহারের জন্য গুগল ফ্রি কোটা অনেক বড় — দিনে শত শত ব্যাকআপেও ছোঁবে না। কার্ডও লাগে না।
