পদ্ধতি খ — অটো ব্যাকআপ (এক ট্যাপে, একবার সেটআপ লাগে)

এতে অ্যাপের ভেতর থেকেই সরাসরি আপনার গুগল ড্রাইভে ব্যাকআপ যাবে ও ফিরবে। গুগল এটি সম্পূর্ণ ফ্রি দেয়। একবার নিচের ধাপগুলো করুন:

১
Google Cloud Console-এ যান ব্রাউজারে (কম্পিউটারে করলে সুবিধা হয়): console.cloud.google.com — আপনার জিমেইল দিয়ে সাইন-ইন করুন।
২
নতুন প্রজেক্ট তৈরি করুন উপরে প্রজেক্টের নামের উপর ক্লিক → New Project → নাম দিন "Amar Hishab" → Create → উপরের তালিকা থেকে এটি বেছে নিন।
৩
Google Drive API চালু করুন উপরের সার্চবারে লিখুন Google Drive API → ঢুকে Enable চাপুন।
৪
OAuth consent screen সেট করুন বাম মেনু → APIs & Services → OAuth consent screen → User Type: External → Create → App name: "Amar Hishab", User support email: আপনার জিমেইল → বাকি ধাপ Next দিয়ে পার হন → শেষে Test users অংশে + Add users করে নিজের জিমেইলটি যোগ করুন।
৫
Client ID তৈরি করুন বাম মেনু → Credentials → + Create Credentials → OAuth client ID → Application type: Web application। নিচে Authorized JavaScript origins-এ আপনার অ্যাপের ঠিকানা যোগ করুন, যেমন: https://আপনার-নাম.netlify.app (শেষে / দেবেন না) → Create।
৬
Client ID অ্যাপে বসান কপি করা xxxx.apps.googleusercontent.com → অ্যাপে আরও → সেটিংস → Google OAuth Client ID ঘরে বসিয়ে সংরক্ষণ করুন।
৭
ব্যবহার শুরু! আরও → ব্যাকআপ ও রিস্টোর → "☁️ ড্রাইভে ব্যাকআপ দিন" — প্রথমবার গুগল অনুমতি চাইবে, Allow করলেই আপনার ড্রাইভে amar-hishab-backup.json ফাইলে সব সেভ হবে। রোজ/সপ্তাহে চেপে রাখুন।
🔒 নিরাপত্তা: অ্যাপটি শুধু drive.file অনুমতি নেয় — এতে অ্যাপটি শুধুমাত্র নিজের তৈরি করা ব্যাকআপ ফাইলটি দেখতে/লিখতে পারে, আপনার ড্রাইভের অন্য কোনো ফাইল বা ছবিতে হাত দিতে পারে না।

৭. 🗓️ প্রতিদিনের ব্যবহারের রুটিন

সময়কাজ
প্রতিটি বিক্রয়েহোম → 🛒 বিক্রয় → পণ্যের নাম লিখে খুঁজে ＋ চাপুন → স্টক নিজে থেকেই কমবে, লাভ নিজে থেকেই হিসাব হবে। বাকি দিলে গ্রাহক বেছে দিন — খাতায় চলে যাবে।
প্রতিটি ব্যাংকিং লেনদেনেহোম → 💸 ব্যাংকিং → সেবা (ক্যাশ ইন/আউট/সেন্ড মানি) → টাকা লিখুন — কমিশন অটো বসবে, ওয়ালেট ব্যালান্স অটো বদলাবে।
প্রতিটি রিচার্জেহোম → 📱 রিচার্জ → অপারেটর + টাকা — কমিশন অটো, অপারেটর ব্যালান্স অটো। ফ্লেক্সিলোড থেকে টাকা তুললে "কমিশন উত্তোলন"।
মাল এলেমুদি → স্টক → পণ্যের পাশে "ক্রয়" → পরিমাণ ও দাম — স্টক বাড়বে; বাকি কিনলে সাপ্লায়ার বাছুন।
খরচ হলে🧾 খরচ → কোন ব্যবসার খরচ সেটা বাছুন (সঠিক ব্যবসার লাভ-ক্ষতি থেকে বাদ যাবে)।
দিন শেষে (২ মিনিট)📊 রিপোর্ট → "আজ" — আজকের মোট বিক্রয়, তিন ব্যবসার আলাদা লাভ ও মোট লাভ দেখুন। হাতের নগদের সাথে মিলিয়ে নিন।
সপ্তাহ/মাস শেষেরিপোর্টে "এই সপ্তাহ/এই মাস" দেখুন + ড্রাইভে ব্যাকআপ দিন।
💡 সমন্বয় (Reconcile) করার নিয়ম: কোনো ওয়ালেট/অপারেটরের ব্যালান্স অ্যাপের সাথে আসল স্টেটমেন্ট না মিললে সেই কার্ডের "সমন্বয়" বাটনে আসল ব্যালান্স লিখে দিন — পার্থক্যটি সমন্বয় হিসেবে যোগ হবে, লাভ-ক্ষতির হিসাব নষ্ট হবে না।

৮. 🎁 আপনার চাওয়ার বাইরে যা যোগ করা হয়েছে (বিনামূল্যে)

  • 💬 এসএমএস রিমাইন্ডার — খাতায় গ্রাহকের নাম্বারে চাপলেই বাকির এসএমএস তৈরি হয়ে যায়, এক ট্যাপে পাঠান (টালি খাতার মতোই) + 📞 সরাসরি কল
  • ⚠️ কম স্টক অ্যালার্ট — কোনো পণ্য সীমার নিচে নামলেই হোমে সতর্কতা
  • 🔐 PIN লক — অন্য কেউ অ্যাপ খুললে হিসাব দেখতে পারবে না
  • 🏆 সবচেয়ে লাভজনক পণ্যের তালিকা — কোন পণ্য থেকে কত লাভ হলো
  • 📋 রিপোর্ট কপি — এক ক্লিকে সারসংক্ষেপ কপি করে কাউকে পাঠানো যায়
  • ➕ নিজের মতো সাজানো — নতুন ওয়ালেট (ট্যাপ/মাকাশ/আইপিএস), নতুন অপারেটর যোগ করা যায়
  • 📊 স্টক ভ্যালুয়েশন — যেকোনো মুহূর্তে "আমার দোকানের মাল কত টাকার (ক্রয়ে/বিক্রয়ে)"
  • 🗓️ পেছনের তারিখে এন্ট্রি — ভুলে গেলে পরে ঠিক তারিখ দিয়ে এন্ট্রি দেওয়া যায়
  • 🧾 লেনদেন মুছলে অটো ফেরত — ভুল বিক্রয় মুছলে স্টক ও খাতা নিজে থেকেই ঠিক হয়ে যায়

১০. 🔄 বিকল্প ফ্রি পথ — Google AppSheet (না-কোডিং)

  1. sheets.google.com-এ একটি শিট বানান (কলাম: তারিখ, ধরন, টাকা, কমিশন...)
  2. appsheet.google.com → Start new app → শিটটি যোগ করুন
  3. View/Form যোগ করে বাটন বানান → ফোনে AppSheet অ্যাপ দিয়ে চালান

কিন্তু সতর্কতা: ফ্রি প্লানে AppSheet-এর নিজস্ব ব্র্যান্ডিং থাকে, রিপোর্ট/কমিশন-রেটের মতো জটিল হিসাব বানানো কঠিন, ইন্টারনেট ছাড়া সীমিত। আপনার তিন-ব্যবসার আলাদা কমিশন হিসাবের জন্য যে অ্যাপ আমি বানিয়ে দিলাম সেটিই বেশি উপযোগী — এটি আপনার একার, কোনো ব্র্যান্ডিং/সীমাবদ্ধতা নেই।

১২. ❓ সাধারণ সমস্যা ও সমাধান (FAQ)

প্রিভিউতে ডেটা সেভ হচ্ছে না কেন?
এখানকার প্রিভিউ শুধু দেখার জন্য। ফাইলটি ফোনে Chrome-এ খুললে বা হোস্ট করলে প্রতিটি এন্ট্রি স্থায়ীভাবে সেভ হবে।
ডেটা উধাও হয়ে গেলে?
ব্রাউজারের "Clear browsing data / site data" দেওয়া হলে এমন হতে পারে। ড্রাইভ-ব্যাকআপ থাকলে রিস্টোর করুন — সব ফিরে পাবেন। এজন্যই নিয়মিত ব্যাকআপ জরুরি।
কমিশন ভুল হিসাব হচ্ছে?
সেটিংসে রেট পরীক্ষা করুন — হাজার প্রতি টাকা ধরে হিসাব হয়। লেনদেনের সময়ও কমিশনের ঘরে হাতে ঠিক করা যায়।
"ড্রাইভে ব্যাকআপ" বাটনে চাপলে কিছু হচ্ছে না?
Client ID ঠিক আছে কি দেখুন; ধাপ ৫-এর ৫ নম্বর কাজে "Authorized JavaScript origins"-এ আপনার অ্যাপের ঠিকানা হুবহু (https:// সহ, শেষে / ছাড়া) দেওয়া আছে কি না মিলিয়ে নিন; ইন্টারনেট চালু আছে কি না দেখুন।
দুইটা ফোনে একসাথে চালাতে পারব?
একসাথে নয় (ডেটা আলাদা জায়গায় জমবে)। ফোন বদলালে: পুরনোটাতে ব্যাকআপ → নতুনটায় রিস্টোর — তাহলেই সব হিসাব নতুন ফোনে।
ক্যাশ আউটে আমার কমিশন ওয়ালেটে যোগ হয় — কিন্তু আমার ক্ষেত্রে নগদে পাই?
সমস্যা নেই: "কমিশন/টাকা উত্তোলন" এন্ট্রি দিলে ওয়ালেট থেকে নগদে চলে আসবে; লাভ-ক্ষতির রিপোর্ট ঠিকই থাকবে। মাঝে মাঝে "সমন্বয়" দিয়ে আসল ব্যালান্স মিলিয়ে নিন।
সব ভুলে গিয়ে নতুন করে শুরু করতে চাই?
আরও → সেটিংস → "সব ডেটা মুছুন" (আগে ব্যাকআপ নিয়েছেন তো?)।
