  1. আরও → সেটিংস → দোকানের নাম লিখুন; "প্রারম্ভিক নগদ তহবিল"-এ আজ হাতে যত টাকা আছে দিন → সংরক্ষণ
  2. একই পেজে নিচে: প্রতিটি ওয়ালেটের (বিকাশ/নগদ/রকেট/উপায়) প্রতি ১০০০ টাকার কমিশন রেট আপনার চুক্তি অনুযায়ী বসান + প্রতিটি অপারেটরের (জিপি/রবি/বাংলালিংক/টেলিটক) রিচার্জ রেট বসান

পদ্ধতি খ — অটো, এক ট্যাপে (শুধু পথ ২-এ চলে; একবার সেটআপ)

এতে অ্যাপের ভেতর থেকেই সরাসরি আপনার ড্রাইভে ব্যাকআপ যাবে-আসবে। সেটআপটা ফোনেই করা যায়, শুধু একটু ধৈর্য লাগে:

  1. Chrome-এ console.cloud.google.com খুলুন → জিমেইল দিয়ে সাইন-ইন → উপরে ☰ → New Project → নাম Amar Hishab → Create (মেনু/অপশন পুরো না দেখালে Chrome-এর ⋮ → Desktop site চালু করুন)
  2. উপরের সার্চে লিখুন Google Drive API → ঢুকে Enable
  3. বাম মেনু APIs & Services → OAuth consent screen → External → App name: Amar Hishab → নিজের জিমেইল দিন → Test users-এ নিজের জিমেইল যোগ করুন
  4. Credentials →＋ Create Credentials → OAuth client ID → Type: Web application → Authorized JavaScript origins-এ দিন আপনার অ্যাপের ঠিকানা (যেমন https://rahim-store.github.io — শেষে / দেবেন না) → Create → Client ID কপি করুন
  5. অ্যাপে: আরও → সেটিংস → Google OAuth Client ID ঘরে বসান → সংরক্ষণ। এরপর আরও → ব্যাকআপ → ☁️ ড্রাইভে ব্যাকআপ দিন — গুগল অনুমতি চাইলে Allow করুন। ব্যস!

শুরুতে হিসাব কম থাকায় পদ্ধতি ক-ই যথেষ্ট — পদ্ধতি খ পরে যখন সময় হবে তখন করুন। বিস্তারিত guideline.html এর ৫ নম্বর ধাপে আছে।

🔧 সমস্যা হলে (ফোন-বিশেষ সমাধান)

Files অ্পে index.html ট্যাপ করলে কিছু খুলছে না?
ফাইলটি বেশিক্ষণ চেপে ধরুন → ⋮ বা তিন-ডট মেনু → Open with → Chrome। তাও না হলে Chrome অ্যাপের অ্যাড্রেস বারে লিখুন file:///sdcard/Download/index.html বা content:// দিয়ে খুঁজুন — অথবা পথ ২ করে ফেলুন, সেটাই ঝামেলাহীন।
GitHub-এ "Settings" বা "Pages" খুঁজে পাচ্ছি না?
Chrome মেনু ⋮ → Desktop site চালু করে পেজ রিফ্রেশ করুন — GitHub মোবাইল ভার্সনে কিছু অপশন লুকিয়ে রাখে। Desktop site চালু করলেই দেখা যায়।
GitHub আপলোডে "choose your files" এ ট্যাপ করে একাধিক ফাইল বাছাই করতে পারছি না?
প্রথম ফাইলে বেশিক্ষণ চেপে ধরে টিক বসান, তারপর বাকিগুলোতে এক এক ট্যাপে টিক উঠবে। না পারলে ৫টি ফাইল ৫ বারে (একটি একটি করে) আপলোড করুন — Add file → Upload files বারবার খুলে।
Pages লিংক খুলছে না (404)?
Save করার পর ১–২ মিনিট সময় দিন, তারপর রিফ্রেশ করুন। ঠিকানায় ইউজারনেম ও রিপোর নাম হুবহু আছে কি না মিলিয়ে দেখুন (বড় হাতের-ছোট হাতের অক্ষরও)। Branch অবশ্যই main ও ফোল্ডার / (root) সেট করতে হবে।
"Add to Home screen"-এ আইকন একটু অন্যরকম দেখাচ্ছে?
সমস্যা নেই — ট্যাপ করলেই অ্যাপ ফুলস্ক্রিনে খুলবে। ইনস্টলের পর একবার ইন্টারনেট চালু অবস্থায় খুলে নিন, তারপর থেকে অফলাইনেও চলবে।
ডেটা সেভ হচ্ছে কি না বুঝব কীভাবে?
অ্যাপের হেডারে ডানে "সেভ চালু ✓" লেখা থাকলে নিশ্চিত থাকুন। আরও নিশ্চিত হতে: একটি বিক্রয় দিন → অ্যাপ বন্ধ করুন → আবার খুলুন — হিসাবটি থেকে গেলেই সেভ হচ্ছে।
ভুলবশত পথ ১-এ অনেক হিসাব দিয়ে ফেলেছি, এখন পথ ২-এ যেতে চাই?
পথ ১-এর অ্যাপ থেকে ⬇️ ব্যাকআপ ফাইল ডাউনলোড করুন → পথ ২-এর অ্যাপ খুলে ⬆️ রিস্টোর করুন → সব হিসাব চলে আসবে। এরপর থেকে শুধু পথ ২-এর অ্যাপ ব্যবহার করুন।
অ্যাপ আপডেট করব কীভাবে (ভবিষ্যতে নতুন ভার্সন এলে)?
পথ ২ হলে: চ্যাট থেকে নতুন index.html ডাউনলোড → GitHub রিপো → Add file → Upload files → নতুন ফাইল দিন ("Commit changes") → ১ মিনিটে অ্যাপ আপডেট। আপনার পুরনো হিসাব অক্ষত থাকবে।
